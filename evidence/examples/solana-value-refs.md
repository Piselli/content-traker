## Value tests (use these)

1. Would a sharp Solana/CT reader **save or cite** this?
2. Is there a **comparison, number, receipt, or non-obvious map**?
3. Does it update “what’s actually happening” — not just opinion cosplay?
4. Format follows content: plate if board, essay if mechanism needs sentences.
