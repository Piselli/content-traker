```
[1–3 line hook] + [native image that IS the info]
```

Image types that count as “цінне”:
1. **Leaderboard / rank flip** — fees, rev, terminals, launchpads
2. **Before/after or $0 vs $raised** — extraction without narrative
3. **Map / list of venues** — stocks on Solana, tools for trenches, reward niches
4. **Time series** — stables supply, consecutive months #1 rev, capacity → TPS/tx
5. **Wallet / flow receipt** — whale still holding, insider cluster, hack drain
6. **One-pic proof** — “show me people prefer building on Solana”
