## X Growth Playbook (primary framework)

**Source:** Practical Playbook built from X open-source algorithm + 2023 weights. Exact numbers may drift; **hierarchy stays**: conversation > applause, blocks destroy reach.

### Core thesis

The algorithm doesn't reward your best post. It rewards the **account** that consistently makes the right people **reply, save, and stay**. Judge the whole account, not each tweet. Stop chasing viral bangers.

### Signal weights (relative to 1 like)

| Action | ≈ value |
|--------|---------|
| **Reply you reply back to** | **150 likes** |
| Reply to your post | 27 likes |
| Profile open → then engage | 24 likes |
| Dwell 2+ minutes | 22 likes |
| Repost | 2 likes |
| Like | 1 |
| Mute / block / "show less" | **−148 likes** |
| Report | buries the post |

**Translation:** 12 replies you answer > 1,000 silent likes. One block ≈ cancels ~148 likes. Bookmarks + DM shares = strong positive (no exact weight in chart, treat as high intent).

### DO / STOP / IGNORE

**DO MORE:** one clear lane · posts people **must** reply to + you reply back · **60 min in comments after every post** · native media that earns the tap · posts worth saving/DMing

**STOP:** chasing likes/bangers · best-time obsession · rage-bait **outside niche** · hashtag stuffing · **links in main post** · 6+ unrelated topics on one account

**IGNORE (dead myths):** best-time charts · "post decays after 6h" · "10 replies in 5 min = viral" · hashtag reach hacks · TweepCred 65

### The 7 Moves (order matters)

**Foundation first (1 + 6) → conversation (2, 3, 5) → polish (4) → never trip 7.**

| Move | Rule | @piselliii map |
|------|------|----------------|
| **1 · One thing** | Stranger names your topic in one word from last 10 posts | Bucket lock = controlled lane: cynical CT + football + crypto (not random viral pivots) |
| **2 · Reply bait + reply back** | Stance + invite correction; answer **80%+ replies within 1h** | `bait`, `provocative`, `strategic QT` — end with real question or debatable claim |
| **3 · First 60 minutes** | Block 60 min after post; ~100% reply rate in hour one | Don't schedule when asleep. Comment section = part of the post |
| **4 · Media earns tap** | Expand photo / watch video scored; decoration isn't | Native charts, collage, video — image must earn the tap; reference: [May 18 algorithm/images thread](https://x.com/piselliii) |
| **5 · Save + DM worthy** | "Would someone screenshot this for one friend?" | `useful` teardowns, lists, frameworks — dwell > fluff |
| **6 · Trusted human** | Following ≤ followers · Premium · 3mo+ · reply to **5 credible niche accounts/day** | No follow/unfollow games. KOL replies = trust signal if on-topic |
| **7 · Right room only** | Wrong-crowd rage-bait = impressions now, blocks later | Provocative OK **inside** CT/football lane; avoid takes that pull outsiders who mute/block |

> A great hook on an untrusted, blurry account still dies — Move 6 before Move 2.

### Playbook → norms + PICK priority

When picking first slot, prefer posts that hit **Move 2 + 3** (reply bait you'll answer) or **Move 5** (save-worthy). Meme/hot topic OK if visual earns the tap (Move 4).

- **Strong post signals:** replies/1k impressions rising · you answered most replies in hour one · bookmarks/DMs (if visible) · dwell-friendly structure
- **Weak post signals:** high views, near-zero replies you didn't answer · impression spike from wrong crowd · blocks/mutes (invisible but shows as flatline after)

### When posts die — run this checklist

| Question | If no / bad → |
|----------|----------------|
| Could a stranger name your topic in one word from last 10 posts? | **Move 1** — lane blur |
| Did last 5 posts invite a real reply? | **Move 2** — no reply bait |
| Were you in replies within 60 min? | **Move 3** — post-and-disappear |
| Is media earning taps, not decoration? | **Move 4** — image/video must earn the expand, not decorate |
| Following ≫ followers / botty patterns? | **Move 6** — trust gate |
| Any post pulling blocks/mutes from outside niche? | **Move 7** — wrong room |
| Strong post *still* dead after all above? | May be safety/spam filter — different problem, not hook |

### Agent: when analyzing screenshots

### Cluster formulas (PICK)

1. **REACH BAIT** (`scorecard` / `collage`) — live stake + visual list or fake score + contrarian punch + reply bait → football bucket
2. **PROOF / SAVE** (`chart` / `screenshot`) — 1-line thesis + native chart or PM screenshot + punchline → useful or hot topic; sources in **first reply**
3. **MEME PUNCHLINE** (`meme`) — recognizable template; joke in image, not explained
4. **QT + ANCHOR** (`screenshot` / `chart`) — strategic QT **only** with own visual; no anchor → skip slot
5. **TEXT-ONLY** — polls/QT without visual → ~200v ceiling; use only if 60 min reply window guaranteed

**Rule:** text = hook, visual = reason to tap. PICK table must include **cluster** column.
