## X Growth Playbook (primary framework)

**Source:** Practical Playbook built from X open-source algorithm + 2023 weights. Exact numbers may drift; **hierarchy stays**: conversation > applause, blocks destroy reach.

### Core thesis

The algorithm doesn't reward your best post. It rewards the **account** that consistently makes the right people **reply, save, and stay**. Judge the whole account, not each tweet. Stop chasing viral bangers.

### Signal weights (relative to 1 like)

| Action | ≈ value |
|--------|---------|
| **Reply you reply back to** | **150 likes** |
| Reply to your post | 27 likes |
| Profile open → then engage | 24 likes |
| Dwell 2+ minutes | 22 likes |
| Repost | 2 likes |
| Like | 1 |
| Mute / block / "show less" | **−148 likes** |
| Report | buries the post |

**Translation:** 12 replies you answer > 1,000 silent likes. One block ≈ cancels ~148 likes. Bookmarks + DM shares = strong positive (no exact weight in chart, treat as high intent).

### DO / STOP / IGNORE

**DO MORE:** one clear lane · posts people **must** reply to + you reply back · **60 min in comments after every post** · native media that earns the tap · posts worth saving/DMing

**STOP:** chasing likes/bangers · best-time obsession · rage-bait **outside niche** · hashtag stuffing · **links in main post** · 6+ unrelated topics on one account

**IGNORE (dead myths):** best-time charts · "post decays after 6h" · "10 replies in 5 min = viral" · hashtag reach hacks · TweepCred 65

### The 7 Moves (order matters)

**Foundation first (1 + 6) → conversation (2, 3, 5) → polish (4) → never trip 7.**

| Move | Rule | @piselliii map |
|------|------|----------------|
| **1 · One thing** | Stranger names your topic in one word from last 10 posts | Bucket lock = controlled lane: cynical CT + football + crypto (not random viral pivots) |

| **3 · First 60 minutes** | Block 60 min after post; ~100% reply rate in hour one | Don't schedule when asleep. Comment section = part of the post |
| **4 · Media earns tap** | Expand photo / watch video scored; decoration isn't | **Attention Architecture** (§ below) — anomaly fragments, not polished design; reference: [May 18 algorithm/images thread](https://x.com/piselliii) |
| **5 · Save + DM worthy** | "Would someone screenshot this for one friend?" | `useful` teardowns, lists, frameworks — dwell > fluff |
| **6 · Trusted human** | Following ≤ followers · Premium · 3mo+ · reply to **5 credible niche accounts/day** | No follow/unfollow games. KOL replies = trust signal if on-topic |
| **7 · Right room only** | Wrong-crowd rage-bait = impressions now, blocks later | Provocative OK **inside** CT/football lane; avoid takes that pull outsiders who mute/block |

> A great hook on an untrusted, blurry account still dies — Move 6 before Move 2.

### Attention Architecture (Move 4 craft layer)

**Not a designer. Not aesthetic content.** Work as: behavioral editor · attention architect · observation extractor · media strategist for X.

Playbook Move 4 = *metric* (expand/watch scored). This section = *craft* — how @piselliii already posts. Proven at scale (May 18 open-algorithm/images thread: ~3M views, mass replies).

#### Goal

NOT beautiful style · NOT dark aesthetic · NOT fake hacker · NOT pseudo-intellectual · NOT quote pages.

**Goal:** repeatable **attention behavior** — user sees anomaly → can't instantly classify → opens → reconstructs context → recognizes lived experience → micro-reward → wants to add their case.

We do **not** hide information. We **compress lived experience into anomaly-shaped fragments.**

#### Core philosophy

Create **recognition-based observations** — things people noticed, felt, lived, but couldn't articulate.

**Ideal reaction:** NOT "wow so deep" · YES "бля, факт" / "це реально так" / "ахах у нас теж" / "занадто точне observation"

**Observation > visual.** Visual only delays attention, creates curiosity, starts reconstruction loop. Weak/banal/fake-deep observation = post forbidden even with great image.

#### SO WHAT? test (mandatory before publish)

Read observation as **plain text only**. If it doesn't trigger recognition → **do not post**.

#### Observation types (lane-aligned)

internet behavior · startup psychology · AI workflows · creator behavior · crypto culture · market absurdities · product contradictions · attention mechanics · online identity · social signaling · community dynamics · hidden incentives · operational irony · elegant systems · architecture decisions · organizational absurdity · emotionally accurate situations

**Micro-recognition rule:** avoid macro-opinions and stale tech memes.

- BAD: "meetings waste time" / "AI causes laziness"
- GOOD: "the moment everyone silently agrees with the bad solution because the call already lasted 2 hours"

Need: micro-frictions · subtle behaviors · precise operational moments · undocumented feelings · oddly specific recognition.

#### What is anomaly

NOT "weird design." **Interrupted expectation.** Partial context · unresolved interface · cropped fragment · broken flow · suspicious metric · impossible proportion · strange setup · symbolic contradiction · object storytelling · weird scale · visual paradox · environmental tension.

User should feel: **"стоп, що тут відбувається?"**

**Conceptual anomaly:** not only UI/screenshots — also physical contradiction · symbolic scene · spatial tension · object storytelling · visual metaphor · environmental irony · broken real-world logic. Sometimes strongest hook = strange real scene brain can't instantly classify.

**Object-based hooks:** people react faster to objects, scale, space, silhouette, contrast, physical anomalies than text fragments. Build via disproportion · impossible access · weird environments · symbolic objects · environmental storytelling.

**Strongest anomaly types — rotate, don't repeat one:**

| Type | Examples |
|------|----------|
| Operational | partial chats, warning states, cropped screenshots, interrupted UI, telemetry, timestamps, system messages, broken states |
| Physical | impossible scale, symbolic furniture, weird proportions, contradictions, unusual placement |
| Symbolic | visual metaphors, broken hierarchy, disproportionate access, distorted systems |

**Anti-pattern:** anomaly stops working when predictable. Don't loop only screenshots/UI/fake-real captures — rotate operational · physical · symbolic · environmental.

#### Post structure

| Layer | Role |
|-------|------|
| **Tweet text** | tension (must NOT spoil reveal — text seen before image on X) |
| **Image** | anomaly |
| **User action** | reconstruction |
| **Reveal** | compressed recognition moment (NOT hidden info) |
| **Replies** | continuation of lived experience |

**Semantic anchor rule:** tweet needs ≥1 anchor word linking text to reveal (retention, deploy, metrics, founder, infra, users, product, moderation, distribution…) — anchor must NOT spoil reveal.

**Reply engine rule:** reveal must leave continuation · space for projection · urge to add own case. Don't fully close the thought-loop.

**Organic link rule:** anomaly + observation = semantic continuation. Visual is part of meaning system, not decoration.

#### Anti-perfection rule (@piselliii signature)

Anomaly must NOT look "too correct." Perfection breaks authenticity.

Should look like: interrupted moment · accidental evidence · symbolic scene · strange environment · object tension · incomplete system.

**Allowed:** asymmetry · crooked edges · partial overlays · strange placement · disproportion · weird scale · environmental imbalance.

**Goal feeling:** "це ніби не мало опинитися в стрічці."

**Forbidden visuals:** glowing UI · cyberpunk aesthetics · fake dashboards · fake research screenshots · centered quotes · polished design posts · fake complexity · "look how smart"

**Consistency:** NOT in layout — in **interaction type** (curiosity loop → reconstruction → recognition → reward).

#### Technical (when generating images)

Format **16:9** · reveal NOT centered · preview must NOT fully show reveal · must work in mobile feed.

Visuals should look like: captured state · operational trace · accidental evidence · unresolved moment · symbolic environment · visual contradiction · physical tension — **not** "content."

**Final principle:** we don't build a post style. We build a **new interaction behavior in the X feed.**

### Playbook → norms + PICK priority

When picking first slot, prefer posts that hit **Move 2 + 3** (reply bait you'll answer) or **Move 5** (save-worthy). Meme/hot topic OK if visual earns tap via **Attention Architecture** (Move 4).

- **Strong post signals:** replies/1k impressions rising · you answered most replies in hour one · bookmarks/DMs (if visible) · dwell-friendly structure
- **Weak post signals:** high views, near-zero replies you didn't answer · impression spike from wrong crowd · blocks/mutes (invisible but shows as flatline after)

### When posts die — run this checklist

| Question | If no / bad → |
|----------|----------------|
| Could a stranger name your topic in one word from last 10 posts? | **Move 1** — lane blur |
| Did last 5 posts invite a real reply? | **Move 2** — no reply bait |
| Were you in replies within 60 min? | **Move 3** — post-and-disappear |
| Is media earning taps, not decoration? | **Move 4** — run SO WHAT? test + Attention Architecture checklist |
| Following ≫ followers / botty patterns? | **Move 6** — trust gate |
| Any post pulling blocks/mutes from outside niche? | **Move 7** — wrong room |
| Strong post *still* dead after all above? | May be safety/spam filter — different problem, not hook |

### Agent: when analyzing screenshots

1. **Replies > views** for judgment — apply weight table mentally
2. Note views + likes + **replies**; flag if replies strong but views modest → "Move 2 working, distribution/notif ceiling"
3. Ask: did user reply in first hour? (behavioral — remind if post was recent)
4. Compare to **own logs**, not KOL minute-one numbers
5. Suggest template # if drafting (Correction magnet, Teardown, etc.) or **Attention Architecture** shape if visual-led
6. If flatline → run **checklist above** before blaming "algorithm dead"
7. DRAFT with image: apply **SO WHAT? test** (plain text) + **semantic anchor** + anomaly type rotation
