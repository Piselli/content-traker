# Compression — tweet craft loop

How @piselliii actually ships. Load on **DRAFT**. AI = compression partner, not thinker-of-record.

## Loop

1. User brings angle (UA ok) + receipts / screenshot / number
2. Draft English punch (1–6 lines) — not essay
3. Kill: AI emdashes, corporate explainers, soft buddy tone, fake wisdom
4. One metaphor max; if it fails, delete — don’t stack analogies
5. Visual last: plate / scorecard / proof screenshot must earn the tap
6. User owns final wording + all live replies

## Compression tests

- Can you cut 40% without losing the mechanism? Do it.
- Is the last line the punch? If punch is buried mid-paragraph → reorder.
- Would a stranger screenshot one sentence for a friend? If no → not save-worthy.
- Reply bait = real question or debatable claim, not “thoughts?”

## Do / don’t

**Do:** contradiction → mechanism → punch · numbers with dates · self-own undercut · QT only with own anchor visual

**Don’t:** roadmap flex · multi-color chart chrome · “we’re cooking” · walls that belong in a Substack · auto-reply voice

## Shapes that compress well

- Scorecard / board gap (StonkFun vs Llama)
- Dead-meta bait (“anyone remember X”)
- Seem vs is reveal (fake PnL / image vs reality)
- One-line QT meme under someone else’s flex
