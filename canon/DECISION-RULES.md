# Decision rules — post / don’t / defer

Load on **PICK**. Keep short. Overrides hype.

## Post when

- You can answer replies for ~60 min after publish
- There’s a real takeaway (comparison, hot fact, mechanism, receipt) **or** intentional support/meme within weekly caps
- Lane fits: Solana eco / CT auditor / StonkFun support / MoveMatch-on-Solana builder
- Visual earns tap **if** the content is board/proof shaped; essays don’t need fake charts

## Don’t post when

- Only chain-flex (Sol fees > ETH) with no deeper map — not your voice
- StonkFun framed as “serious value teardown” when it’s really support
- Meta/reach essay as slot 1; meta already at cap
- Meme already at 1–2 for the week and you’re forcing another
- Football filler while EPL/project quiet (unless genuine hot)
- Reply window unavailable → defer, don’t schedule-and-ghost

## Defer when

- Receipts incomplete but angle is good — wait one print
- Same mechanism posted <48h ago — let it breathe
- Builder/MoveMatch would contaminate a strong value week — cap ≤2
